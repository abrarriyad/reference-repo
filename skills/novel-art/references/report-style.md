# Design conventions for the art report

The report is generated by `scripts/novel-art.mjs render --html`, and all styling is inlined in `renderHtml()`. **Change styling in that one place only.**

It shares one visual language with the other two reports: cool-grey stamp paper + rust-red seal marks, 1600 wide, everything laid flat so Cmd+F works, zero external dependencies, opens offline with a double-click.

## Structure

```
Header    Title · scene bible · art style · quality-gate badge · export JSON
KPI band  Scene count (main + variants) / consistency anchors / lighting states / reused variants
(Problem banner)  Appears only when a quality gate has not passed
01 Scene list    One master table: ID / type / episodes / anchor count / lighting / variant changes
03 Prop list 04 Prop cards    Rendered only when props exist; a prop card mirrors a scene card (state variants replace lighting, a badge shows scale)
02 Scene cards  One large card per scene (the body of the report)
03 Quality gates    Full ✓/✗ checklist
```

## Scene cards

**Two per row** (one column below 1100px), with the card content stacked vertically — this layout was chosen for promo screenshots: the sheet image fills the card width and sits near the top, so two cards side by side cropped out make one image fit to post.

Top to bottom inside a card: card header (ID + name + badge + episodes) → design intent (serif type; it is narrative, not parameters) → **environment sheet** (clickable, opens a larger view in an overlay, closed with Esc or a click on the background; a placeholder if no image yet) → variant-source note (rust-red background) → **consistency anchors** (numbered list, monospaced `01 02 03` numerals — it is a checklist, and the numbers are for QC to read aloud) → **lighting and time of day** (state name + prompt, each line with a copy button) → prompt pack (collapsed + copy: main view / sheet / negative + whole-card JSON).

## Quality gates

11 gates (7 for scenes and shared + 4 for props), computed by `gateReport()` at render time and baked into the page. For a document with no props, the four prop gates pass automatically and still display. One special case: "prompts contain no character names" **says plainly that it was skipped** when no cast.json was given (the panel reads "cast.json not provided, this gate skipped"), and does not pretend to have checked — silent passing and lying are one step apart.

## Export JSON

Same as the other two skills: `<script type="application/json" id="scenes-data">` embeds the data verbatim + a header button downloads it. The same two pitfalls apply: escape `<` as `\u003c` so `</script` cannot truncate it; delay the `revokeObjectURL` call so Safari does not save an empty file.

## Quality floor

- All model-generated data goes through `esc()` escaping
- `@media print`: hide buttons, expand prompts fully, never break a card across pages
- `prefers-reduced-motion` turns off animation
- Chinese copy avoids single-character words (copy / expand / main scene — do not write them as single characters)
